# Day 2 BNSP — Curriculum Vitae HTML

## Deskripsi
Proyek ini merupakan latihan membuat Curriculum Vitae (CV) sederhana menggunakan HTML. Tujuannya adalah mempelajari struktur dasar HTML untuk menampilkan informasi diri dalam bentuk halaman web.

## Materi yang Dipelajari
- Struktur dasar HTML.
- Penggunaan heading, paragraf, dan garis pemisah.
- Penggunaan list untuk menampilkan riwayat pendidikan dan pengalaman organisasi.
- Penggunaan tag HTML semantik seperti `header`, `main`, `section`, dan `footer`.
- Penggunaan atribut `style` untuk mengubah warna teks.

## Isi CV
1. Profil Diri
2. Tentang Saya
3. Riwayat Pendidikan
4. Pengalaman Organisasi
5. Keahlian
6. Hobi

## Teknologi
- HTML5

## Kesimpulan
Melalui latihan ini, saya belajar membuat halaman CV sederhana menggunakan HTML dan memahami fungsi beberapa elemen HTML dalam menyusun informasi agar lebih terstruktur dan mudah dibaca.
